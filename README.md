# 🌿 Greenden - Plant Store Website

Greenden is a simple and responsive plant store website built using **HTML** and **Tailwind CSS**. This project was created as part of my frontend development learning journey to practice building modern, responsive web layouts using the Tailwind CSS framework.

## 🚀 Features

* Responsive design for desktop, tablet, and mobile devices
* Modern and clean user interface
* Navigation bar with responsive layout
* Hero section
* Product showcase section
* Customer reviews section
* Newsletter subscription section
* Footer with useful links
* Built using utility-first Tailwind CSS classes

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS

## 📚 What I Learned

While building this project, I practiced:

* Creating responsive layouts with Tailwind CSS
* Using Flexbox and Grid
* Working with Tailwind utility classes
* Building reusable UI sections
* Improving webpage structure using semantic HTML
* Organizing and styling components efficiently

## 🎯 Purpose

This project was created for learning and practice purposes. It helped me strengthen my understanding of responsive web design and Tailwind CSS while recreating a modern plant store website.
